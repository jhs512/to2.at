# Owner는 카카오 로그인으로 API 키를 발급한다

카카오 세션을 개인 스킬로 옮기는 절차가 번거롭다는 사용자 요청으로 ADR 0005의 Owner 인증을 확장한다. 카카오 로그인은 신원 확인과 키 관리에 계속 사용하고, API 키는 같은 Owner의 Link 자동화에 사용한다. Operator 경로는 바꾸지 않는다.

원문 키는 발급 때 한 번만 반환하고 SHA-256 해시만 보관한다. 256비트 무작위 비밀에는 비밀번호처럼 느린 해시가 필요하지 않다. 여러 클라이언트가 키를 따로 폐기할 수 있도록 여러 키를 허용한다.

키 관리에는 카카오 로그인이 필요하다. API 키가 키 관리 권한까지 갖는 대안은 유출된 키로 새 키를 만들어 폐기를 무력화할 수 있어 제외한다. Bearer 인증은 Link API와 /me에 한정하고 세션으로 저장하지 않는다. 만료 일정 대신 명시적 폐기를 제공한다. 유출 시 로그인하여 해당 키를 폐기하고 새 키를 발급한다.
