# Code는 순차 정수로 발급한다

`to2.at/1`, `to2.at/2` 형태를 쓴다. 가장 짧고 읽기 쉬우며, 숫자 전용이라 프론트 라우트(`/dashboard` 등)와 절대 충돌하지 않아 `/^\/\d+$/` 하나로 갈린다.

**의도된 대가: Code가 열거 가능하다.** 1부터 훑으면 모든 Link의 Target이 드러나고, 최대 Code 값으로 전체 생성량도 드러난다. 리다이렉트는 공개여야 하므로 인증으로 막을 수 없다. 개인·지인 공유 용도라는 전제에서 수용한 것이며, 전제가 바뀌면 재검토 대상이다.

그래서 **Code 발급을 함수 하나로 격리한다.** DB의 기본키는 정수로 유지하므로, 나중에 난독화(Sqids/Feistel 등)로 바꿔도 스키마 마이그레이션 없이 그 함수만 교체하면 된다.
