# 11: 개발 시드 계정

**What to build:** 개발자가 카카오를 거치지 않고 Owner 흐름을 돌려볼 수 있게, 로컬에서만 아이디/비밀번호로 들어갈 수 있는 샘플 계정이 생긴다. 운영에서는 만들어질 방법이 없다.

**Blocked by:** 08 (로컬 계정 저장소와 폼 로그인)

**Status:** done

- [x] 개발 프로필에서만 `admin`과 샘플 Owner 세 개(`user1`, `user2`, `user3`)가 생성된다
- [x] 샘플 Owner 계정으로 로그인해 Link 생성·목록·삭제를 카카오 없이 끝까지 해볼 수 있다
- [x] 샘플 계정의 카카오 주체 값은 합성 값을 쓴다. **주체 컬럼을 nullable로 열지 않는다** (ADR 0005 — "카카오 계정 하나가 Owner 하나에 대응한다"는 불변식을 구조적으로 유지한다)
- [x] 비밀번호는 기동 시점에 해싱된다. 시드는 마이그레이션이 아니라 개발 프로필에서만 도는 실행기가 만든다 — 비밀번호 인코더에 접근할 수 있는 유일한 방법이다
- [x] **어떤 마이그레이션도 계정을 만들지 않는다**
- [x] 개발 전용 마이그레이션이 있다면 운영 마이그레이션 트리 **바깥의 별도 루트**에 두고 겹치지 않는 버전 대역을 쓴다. 운영의 마이그레이션 검증이 영향받지 않는 것을 확인한다
- [x] 운영 프로필로 기동하면 샘플 계정이 생성되지 않는다
- [x] `admin`은 Owner를 가리키지 않는다. 샘플 사용자 계정만 각자의 Owner를 가리킨다
