# 10: 크롤러 302 분기

**What to build:** 짧은 주소를 카카오톡에 붙이면 Target의 실제 미리보기 카드가 뜬다. 받는 사람이 뭐가 오는 링크인지 알 수 있게 된다.

**Blocked by:** 03 (크롤러는 공개 URL에만 접근하므로 배포 없이는 최종 확인이 불가능하다), 09 (중지 상태가 있어야 중지된 Link의 분기를 만들 수 있다)

**Status:** done (운영 확인 1건은 03번 배포 이후로 남음)

- [x] 링크 미리보기 크롤러로 판별되면 활성 Code는 Target으로 302 응답한다. 카카오는 리다이렉트를 따라가 도착지를 스크랩하므로, Target의 Open Graph 태그를 긁어 저장할 필요가 없다
- [x] 크롤러 판별은 User-Agent 부분 문자열로 한다. 카카오의 UA에는 다른 크롤러 이름도 함께 들어 있으므로, 카카오 고유 부분에 맞춰야 한다
- [x] **중지된 Link는 크롤러에게도 302를 주지 않는다** (ADR 0004). 주면 차단해놓고도 카드에는 Target이 그대로 뜬다
- [x] 존재하지 않는 Code는 크롤러에게 302를 주지 않는다
- [x] 사람의 요청은 여전히 Interstitial을 받는다
- [x] **Interstitial이 요청 URL과 다른 Open Graph 정규 URL을 내보내지 않는다** — 다르면 카카오가 그 주소를 다시 긁으러 간다
- [ ] 운영에 배포된 짧은 주소를 카카오톡에 붙여 Target의 카드가 뜨는 것을 직접 확인한다. 카카오의 미리보기 캐시는 약 1시간이고 일괄 초기화 수단이 없으므로, **첫 공유 전에 맞춰둔다**
