# 09: Suspension과 관리자 화면

**What to build:** Operator가 신고 목록을 보고 문제 있는 Link를 끊는다. 중지된 Link는 Visitor에게 차단 안내만 보이고 Target은 드러나지 않는다.

**Blocked by:** 07 (볼 신고가 있어야 한다), 08 (Operator 로그인)

**Status:** done

- [x] Operator가 신고 목록을 본다. 각 항목에 대상 Code, Target, 그 Link가 받은 신고 수가 보인다
- [x] 목록에서 한 번의 동작으로 Link를 중지한다
- [x] 중지를 해제할 수 있다 (오판을 되돌리기 위해)
- [x] 신고를 처리완료로 표시해 남은 일이 무엇인지 목록에 드러난다
- [x] **신고가 없어도 Operator가 임의의 Link를 중지할 수 있다** — 신고를 기다릴 필요 없는 명백한 경우가 있다
- [x] 서로 다른 출처에서 온 신고가 임계값을 넘으면 검토 전에도 자동으로 중지된다 (Operator가 며칠 못 볼 때의 안전망)
- [x] 중지된 Code를 연 Visitor는 차단 안내만 본다. **Target은 화면에 나타나지 않는다** — 보여주면 중지의 의미가 없다
- [x] Owner의 목록에서 자기 Link가 중지됨으로 표시된다
- [x] Owner 세션과 익명 요청은 관리자 엔드포인트에서 거부된다
- [x] 이의제기 경로는 만들지 않는다 (범위 밖)
