# 08: Operator 로그인

**What to build:** Operator가 공개 사이트에 링크되지 않은 경로에서 아이디와 비밀번호로 로그인한다. 반복 실패하면 잠긴다.

**Blocked by:** 04 (공개 체인이 먼저 있어야 두 체인이 서로 간섭하지 않음을 증명할 수 있다)

**Status:** done

- [x] 공개 사이트 어디에도 링크되지 않은 경로에서 아이디/비밀번호로 로그인한다
- [x] **필터 체인이 두 개로 나뉜다** (ADR 0005). 관리자 체인은 그 경로에만 매처를 걸고 폼 로그인만, 공개 체인은 매처 없이 마지막에 오며 OIDC 로그인만 켠다. 하나로 합치면 설정 호출 순서에 따라 동작이 달라진다 — 등록된 OAuth2 클라이언트가 하나뿐이면 진입점이 곧장 제공자로 가버리기 때문이다
- [x] **테스트가 체인 분리를 증명한다**: 공개 경로의 미인증 요청은 카카오로, 관리자 경로의 미인증 요청은 폼으로 간다
- [x] Operator 비밀번호는 **환경변수에서만** 온다. 마이그레이션에도 코드에도 평문·해시 어느 쪽도 없다
- [x] 비밀번호 해시는 알고리즘 접두사를 포함해 저장된다
- [x] 설정된 횟수만큼 실패하면 계정이 잠기고, 설정된 시간이 지나면 풀린다. 프레임워크에 브루트포스 방어가 없으므로 인증 실패 이벤트와 계정 잠금 플래그로 직접 만든다
- [x] Operator 계정으로는 Link를 만들 수 없다 (Operator는 Owner가 아니다)
