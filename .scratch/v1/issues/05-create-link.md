# 05: Link 생성

**What to build:** 로그인한 Owner가 Target을 붙여넣으면 Code가 발급되고, 복사할 수 있는 짧은 주소가 나온다. 발급되는 Code는 빈틈없이 연속한다.

**Blocked by:** 02 (입력 화면이 놓일 SPA), 04 (로그인한 Owner)

**Status:** done

- [x] 로그인한 Owner가 Target을 입력하면 Code가 발급된다
- [x] 전체 짧은 주소가 복사 버튼과 함께 표시된다
- [x] `http`와 `https`가 아닌 Target은 명확한 메시지와 함께 거부된다
- [x] 이 서비스 자신의 도메인을 가리키는 Target은 거부된다 (리다이렉트 루프 방지)
- [x] **연속해서 만든 Code 사이에 빈틈이 없다.** 시퀀스 할당 크기를 1로 두어 ORM 기본값 50이 만드는 구멍을 없앤다 — 재시작이 잦은 환경에서 실제로 벌어지는 문제다
- [x] 애플리케이션을 재시작한 뒤 만든 Code도 직전 Code의 바로 다음이다
- [x] 같은 Target을 두 번 넣으면 Link가 두 개 생긴다 (중복 제거하지 않는다)
- [x] 로그인하지 않은 요청은 생성할 수 없다
