# 04: 카카오 로그인과 Owner

**What to build:** 카카오 계정으로 로그인하면 Owner가 자동으로 만들어지고 닉네임이 보인다. 별도 가입 단계는 없다. 세션은 재시작을 견딘다.

**Blocked by:** 01 (스키마와 애플리케이션이 있어야 한다)

**Status:** done

- [x] 로그인이 필요한 곳을 열면 **중간 로그인 화면 없이 곧바로 카카오로** 간다
- [x] 최초 로그인 시 Owner가 자동 생성되고, 카카오 주체 값이 불변 식별자로 저장된다
- [x] 닉네임이 화면에 보인다
- [x] 이메일은 nullable이며, 카카오가 검증했다고 표시한 경우에만 신뢰한다. 이메일을 식별자로 쓰지 않는다
- [x] 카카오는 OIDC 발급자 URI로 설정한다. **클라이언트 인증 방식을 명시적으로 지정하지 않는다** — 카카오는 한 가지만 광고하고 discovery가 그것을 고르며, 명시하면 토큰 교환이 조용히 깨진다
- [x] scope는 카카오 고유의 동의 항목 식별자를 쓴다 (표준 OIDC 이름이 아니다)
- [x] 세션이 데이터베이스에 저장되어 애플리케이션을 재시작해도 로그인이 유지된다
- [x] 세션 고정 전략은 기본값을 유지한다. 세션 속성을 버리는 전략은 진행 중인 OAuth 핸드셰이크를 떨어뜨린다
- [x] 세션 쿠키가 `SameSite=Lax`다. **`Strict`가 아님이 확인된다** — Strict면 카카오 콜백에서 쿠키가 실리지 않아 로그인이 통째로 깨진다
- [x] CORS가 사이트 오리진만 허용하고 자격 증명을 통과시킨다
- [x] 로그아웃이 동작한다
- [x] 테스트는 카카오를 실제로 호출하지 않고 보안 테스트 모듈의 OIDC 로그인 지원으로 Owner 세션을 재현한다
